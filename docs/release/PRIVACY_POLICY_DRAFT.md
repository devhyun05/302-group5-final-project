# AURA Privacy Policy Draft

이 문서는 AURA iOS 앱의 개인정보 처리방침 초안입니다.
실제 배포 전에는 운영 회사명, 문의 이메일, 지원 URL, 데이터 보관 기간을 확정해 업데이트해야 합니다.

## 1. 처리하는 데이터

AURA는 얼굴 촬영과 AI 메이크업 분석을 제공하기 위해 다음 데이터를 처리할 수 있습니다.

- 사용자가 카메라로 촬영한 얼굴 이미지
- 사용자가 사진 보관함에서 선택한 이미지
- AI 분석 결과
- 앱 사용 중 생성되는 기본 진단 상태와 추천 결과

현재 앱은 로그인 없이 사용할 수 있도록 구성되어 있으며, 이름, 이메일, 전화번호 입력을 필수로 요구하지 않습니다.

## 2. 사용 목적

수집 또는 처리되는 이미지는 다음 목적에만 사용합니다.

- 얼굴 촬영 화면 미리보기
- AI 메이크업 분석
- 분석 결과 화면 표시
- 추천 메이크업 룩과 제품 추천
- 사용자가 요청한 메이크업 룩 생성 흐름

얼굴 이미지와 얼굴 분석 데이터는 광고, 마케팅, 사용자 추적, 데이터 마이닝 목적으로 사용하지 않습니다.

## 3. 카메라와 사진 접근

앱은 얼굴 촬영과 AI 분석 미리보기를 위해 카메라 권한을 요청합니다.
앱은 사용자가 선택한 사진으로 AI 분석 흐름을 제공하기 위해 사진 보관함 권한을 요청합니다.
권한을 거부해도 앱은 크래시되지 않아야 하며, 사용자는 홈 또는 이전 화면으로 돌아갈 수 있어야 합니다.

## 4. 서버 업로드와 OpenAI API

분석 기능은 백엔드를 통해 OpenAI API 또는 별도 AI 처리 시스템을 사용할 수 있습니다.
React Native 앱에는 OpenAI API key를 저장하지 않습니다.
서버 업로드가 실패하는 경우 앱은 로컬 이미지 URI 또는 mock 데이터 기반 fallback으로 화면 흐름을 유지합니다.

## 5. 보관 및 삭제

얼굴 원본 이미지는 서비스 제공에 필요한 기간 동안만 처리하는 것을 원칙으로 합니다.
정식 배포 전 운영 정책에 따라 다음 내용을 확정해야 합니다.

- 원본 이미지 보관 여부
- 원본 이미지 보관 기간
- 분석 결과 보관 기간
- 사용자 삭제 요청 처리 방법
- 백업 데이터 삭제 주기
