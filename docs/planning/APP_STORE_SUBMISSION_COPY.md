작성일: 2026-07-01

## App Store 제품 페이지

### 앱 이름

```text
AURA 퍼스널컬러
```

대안:

```text
AURA 컬러 이미지 체크
```

### 부제

```text
사진 없이 컬러와 이미지 체크
```

### 프로모션 문구

```text
사진 촬영 없이 34개 설문으로 나에게 어울리는 컬러, 이미지 무드, 헤어, 패션과 메이크업 방향을 가볍게 확인해보세요.
```

### 설명

```text
AURA는 사진 촬영이나 업로드 없이 설문 답변만으로 퍼스널 컬러와 이미지 타입 경향을 확인하는 뷰티 참고 앱입니다.

34개의 간단한 질문에 답하면 앱 안에서 바로 결과 리포트를 만들어요. 결과에는 퍼스널 컬러 방향, 이미지 타입 키워드, 추천 헤어, 추천 패션/핏, 추천 컬러 팔레트, 추천 메이크업 팁, 피하면 좋은 표현이 함께 정리됩니다.

주요 기능

- 사진 없이 시작하는 설문 기반 컬러 체크
- 퍼스널 컬러와 이미지 타입 결과 리포트
- 어울리는 헤어 실루엣과 헤어 컬러 제안
- 체형 밸런스와 취향 답변을 바탕으로 한 패션/핏 제안
- 답변 경향을 바탕으로 한 추천 메이크업 팁
- 최근 결과 저장 및 다시 보기
- 결과 이미지 저장 및 공유 기능

AURA는 카메라 촬영, 사진 업로드, 회원가입, 서버 업로드 없이 사용할 수 있습니다. 설문 답변과 최근 결과는 기기 안에서 처리되며, 결과 이미지를 사진 앱에 저장할 때만 iOS 사진 추가 권한을 요청합니다. 결과 공유는 사용자가 선택한 iOS 공유 기능을 통해서만 진행됩니다.

결과는 설문 답변의 경향을 정리한 뷰티 참고 정보입니다. 실제 메이크업에서는 피부 상태, 조명, 취향, 제품 발색에 따라 밝기와 채도를 조절해보세요.
```

개인정보 처리방침 페이지에 넣을 문구:

```text
AURA 개인정보 처리방침

시행일: 2026년 7월 1일

AURA는 사진 없이 설문 답변을 바탕으로 퍼스널 컬러, 이미지 타입, 헤어와 패션 경향을 확인하는 뷰티 참고 앱입니다.

1. 처리하는 정보
AURA는 사용자가 앱 안에서 선택한 설문 답변, 설문 결과, 최근 결과 기록을 기기 안에 저장할 수 있습니다. 이 정보는 앱 기능 제공을 위해 사용됩니다.

2. 사용하지 않는 정보
현재 앱은 회원가입, 로그인, 카메라 촬영, 사진 업로드, 서버 업로드를 사용하지 않습니다. 사용자의 사진, 얼굴 이미지, 이름, 연락처, 위치 정보는 요청하지 않습니다. 결과 이미지를 사진 앱에 저장할 때만 사진 추가 권한을 요청합니다.

3. 정보 저장 위치
설문 답변과 결과는 사용자의 기기 안에서 처리됩니다. 앱 운영자가 별도 서버로 설문 답변이나 결과를 전송하지 않습니다.

4. 결과 저장 및 공유
사용자가 결과 이미지 저장을 선택하면 결과지가 이미지로 생성되어 사용자의 사진 앱에 저장됩니다. 사용자가 공유 기능을 선택하면 iOS 공유 기능이 열립니다. 사용자가 선택한 공유 대상에 전달된 정보는 해당 서비스의 개인정보 처리방침을 따릅니다.

5. 결과의 성격
AURA의 결과는 설문 답변 경향을 정리한 뷰티 참고 정보입니다. 의학적 진단, 피부 질환 판단, 전문 색채 진단, 정확도 보장을 의미하지 않습니다.

6. 문의
```
