SCREEN 01

홈 — 초보자 진입점

프리셋 칩 하나 → 셔터로 끝. 고급으로 가는 문은 딱 둘.

  • 프리셋 칩 — 탭하면 얼굴이 그 룩으로 즉시 전환
  • ◈ 내 스타일 — 저장한 커스텀이 여기 쌓임
  • ＋ 만들기 — 컴포저 진입
  • 전역 농도 바 — 밀면 전체 진하기 실시간
▶ 프리셋 칩을 눌러 얼굴을 바꿔보세요. 전역농도 바도 밀어보세요.
SCREEN 02 · R8

레이어 스택

모든 부위가 레이어 한 장씩. 아래→위=그리는 순서.

  • ◉ 눈=켜기/끄기 → 얼굴에서 그 부위가 사라지고 나타남
  • 행 탭=축 편집기 로드
  • ＋ 레이어 추가=16개 부위
▶ 눈알(◉)을 눌러 립·렌즈를 켜고 꺼보세요.
SCREEN 02b

부위 선택 — 전 16종

전용 메시(정밀) 부위 + 자유배치(캐노니컬).

  • 피부/베이스 — 베이스·피부보정·톤업·컨실러·하이라이터·컨투어
  • 볼 — 블러셔
  • 눈 — 섀도·라인 상/하·애교살·속눈썹·렌즈
  • 눈썹·립·데코
SCREEN 03 · R5

축 편집기 — 부위 연동 + 라이브

대상 부위를 바꾸면 축이 따라 바뀌고, 색을 고르면 얼굴이 즉시 반영됩니다.

  • 대상 → 16부위 · 자유배치
  • 색 스와치 탭 → 해당 부위 즉시 리컬러
  • 06 농도 슬라이더 → 그 부위 진하기
▶ 대상=립 → 색 스와치를 바꿔보세요. 입술색이 즉시 변합니다.
SCREEN 04 · R7

핏 워프 — 밀어서 변형

얼굴 형태 조정. 골드 핸들 드래그 or 슬라이더.

  • 방사 — 눈확대·입크기·코끝
  • 윤곽밀기 — 턱슬림·V라인·콧대…
  • 방향이동 — 눈꼬리·입꼬리·눈간격
▶ 눈·입 위 골드 핸들을 드래그하거나 슬라이더를 밀어보세요.
SCREEN 05 · R10

저장 · 재사용 (루프 완성)

레이어·워프·색·농도를 내 스타일로. 프리셋과 나란히.

  • 이름·커버·요약 자동
  • 저장 → 홈에 ◈칩 실제 추가
  • 홈에서 ◈칩 탭=재적용 · 롱프레스=편집
▶ 저장을 누른 뒤 홈으로 가서 새로 생긴 ◈칩을 눌러보세요.
