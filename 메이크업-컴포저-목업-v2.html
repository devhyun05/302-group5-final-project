메이크업 컴포저 v2 — 조합의 조합

보정(형태)과 메이크업(색·질감)은 별도 레인으로 자유롭게 섞이고, 메이크업 룩은 전체 룩 = 부위 룩의 합 = 세부 룩의 합 = 제품 적용(겹겹이)의 합이라는 재귀 조합으로 정의됩니다. 편집은 언제나 사본 위에서(원본 불변), 확인은 저장 때 시트 한 장으로.

⚠ 본 목업은 07-11 §5 이전 규약 — (a) 저장 2레인 pair→3종 레인별 분리(내 룩·내 보정·내 핏)로 대체, (b) 제품=표시 라벨→1급 엔티티(A12), (c) ‘제품 적용 1회’ 평면 스키마→제품(참조)×테크닉+역할 태그, 핏은 시트 캐스케이드(A13), (d) 스타일 로드가 보정 레인을 덮는 동작은 폐기됨(splitWarpLane 이관). UI 상호작용(트리·copy-on-write·표시 역순)은 여전히 유효. 정본: 분류체계 §5.

SCREEN 01 · V2

홈 — 두 레인이 나란히

LOOK(메이크업 룩)와 FIT(보정 필터)는 서로 다른 종류의 필터. 각자 고르면 자유 조합됩니다. 두 레인 모두 ＋만들기로 직접 조합할 수 있어요.

  • LOOK 칩 — 전체 룩(하위 룩들의 합). 탭=즉시 적용
  • FIT 칩 — 눈확대·턱슬림 같은 형태 보정 세트. 항상 별도 레인
  • 농도/강도 — 레인별 마스터 슬라이더
  • ◈ 내 스타일 = 두 레인을 참조하는 한 쌍 · 롱프레스 = 그 스타일 편집(저장 때 덮어쓰기)
▶ 로지 + 또렷한눈을 각각 켜 보세요. 상태칩에 "로지 + 또렷한눈" 조합이 표시됩니다.
SCREEN 02 · V2

룩 트리 — 조합의 조합, 화면 이동 없이

전체 룩 = 부위 룩의 합 = 세부 룩의 합 = 제품 적용(겹겹)의 합. 4계층이지만 전부 한 시트 안에서 펼쳐집니다(뎁스는 세로 스크롤로만).

  • 행 탭 = 아코디언 펼침 (드릴다운 화면 전환 없음)
  • ⇄ 교체 = 같은 자리에 라이브러리의 다른 룩 갈아끼우기
  • 같은 제품 ×2 — 로즈 그라데 섀도는 파우더 섀도 2겹(아래→위 = 그리는 순서)
  • 수정하면 *가 조상까지 전파 — 원본 정의는 불변
▶ 홈에서 로지를 적용한 뒤 — 눈 행을 펼치고 → 로즈 그라데 섀도를 펼치면 같은 제품 2겹이 보입니다. 립 행의 ⇄로 룩을 교체해보세요.
SCREEN 02b

부위 선택 — 전 16종

전용 메시(정밀) 부위 + 자유배치(캐노니컬). 선택하면 해당 슬롯에 새 부위 룩이 생깁니다.

  • 피부/베이스 — 베이스·피부보정·톤업·컨실러·하이라이터·컨투어
  • 볼 — 블러셔
  • 눈 — 섀도·라인 상/하·애교살·속눈썹·렌즈
  • 눈썹·립·데코
SCREEN 03 · V2

축 편집기 — 잎(제품 적용)의 6축

트리의 잎 하나 = 제품 적용 1회. 경로 표시줄이 어느 룩의 어느 겹인지 보여줍니다.

  • 경로 — 로지* › 로즈브라운 아이 › 윙업 라인 › 젤 라이너
  • 색·농도 조작 → 얼굴 즉시 반영 + 조상에 * 전파
  • 편집 중에는 절대 묻지 않음 — 전부 사본 위 작업

⚠ 축 6종=모양·텍스처·색·마감·농도·핏(골드=핏 시트 편집 표면) — ‘대상’은 축이 아니라 선택 헬퍼. 잎 스키마는 pre-§5.

▶ 색 스와치를 바꾸면 립/눈이 즉시 변하고, 트리로 돌아가면 *가 붙어 있습니다.
SCREEN 04 · V2

보정 레인 — 항상 별도 트랙

형태 보정은 메이크업 조합에 절대 섞여 들어가지 않는 독립 레인. 자체 프리셋(필터)을 갖고, 자체적으로 저장됩니다.

  • FIT 프리셋 칩 — 자연보정·또렷한눈·V라인·인형눈
  • 방사/윤곽밀기/방향이동 — 오퍼레이터 3종
  • 슬라이더를 만지면 또렷한눈* — 사본 규칙 동일
  • 필터로 저장 → 홈 FIT 레인에 ◈칩 추가
▶ 프리셋 칩을 고른 뒤 슬라이더를 밀면 칩에 *가 붙습니다. "필터로 저장"으로 내 보정 필터를 만들어보세요.
SCREEN 05 · V2

저장 시트 — 확인은 여기서 한 번

편집 중 무질문 원칙의 짝: 저장 때 변경 요약 시트 한 장으로 전부 해결. 대부분은 물어볼 게 없습니다.

  • 기본 프리셋 수정분 → 자동 "사본으로 포함" (원본 불변, 질문 없음)
  • 중간 계층 → 기본은 익명으로 상위에 묻어감 · "☆ 따로 저장"으로만 라이브러리 승격
  • 내가 만든 룩 + 다른 룩에서도 사용 중 → 그때만 선택지: 이 룩에서만(사본) / 원본에 반영(공유처 N개에 적용)
  • 저장물 = 메이크업 룩 + 보정 세트 두 레인 참조 한 쌍

⚠ 구 2레인 pair 규약 — 07-11: 3종 레인별 분리, ‘스타일’은 예약어.

▶ 립을 "벨벳로즈+"(내 룩)로 교체해 색을 바꾼 뒤 저장하면, 공유 중인 룩에 대한 선택지가 나타납니다.
